# Security and privacy

Do not open an issue containing a password, NetID, subscription URL, Reality private key, UUID, device ART/calibration, raw partition image, private configuration archive or packet capture.

This repository uses documentation addresses and invalid placeholder credentials. Generated candidates and downloaded rule files stay under ignored `local/`. The offline panel binds only to loopback, checks Host/Origin and cannot deploy to a router. Do not change it to listen on a LAN/WAN address without adding an appropriate authentication design.

Reference router scripts change networking when executed and require the documented integration. They are not a universal installer. Keep wired management, verified private backups and an independently running rollback guard before adapting them.

The public audit catches common signatures and forbidden artifacts, not every possible secret. Review both working files and Git history before publication. Report a suspected issue without including sensitive payloads; use GitHub private vulnerability reporting if it is available on this repository.
