# 测试数据

## 2026 年 11 月 · Athena 软件转发

[下载、WAN6 与无线汇总](athena-software-2026-11.csv)保留各轮的统计口径。路由器物理 WAN 接收量包含协议开销与其他流量，应用有效速率单独列出。

- **五路 Steam 对照**。软件流表与下行放行同时启用时，物理 WAN 接收中位数 443.7 Mbps，Steam 套接字有效速率中位数 404.5 Mbps。整机四核忙碌中位数 60.1%。
- **WAN6 专用**。前五路下载约 439.3 Mbps 的窗口内，合成游戏式 UDP 有线 6,934/6,934、Wi-Fi 3,477/3,477。此前的六路混合下载为 WAN6 可借线时的实验。
- **游戏回退**。约 260 Mbps 下载负载下，新建有线 UDP 流回退到 WAN5，首个回包约 38 ms，32.3 秒内收到 2,038/2,038 个回包。
- **802.11v 下载引导**。Android 手机以 448.9 Mbps 完成单连接下载，接受从信道 149 到 36 的建议。游戏电脑保持在 149，Wi-Fi 合成 UDP 收到 3,070/3,070 个回包。

以上是短窗口测量。UDP 对照覆盖指定探测端点，真实比赛的 Loss/Miss、高峰时段和长时间稳定性待验证。
