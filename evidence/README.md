# 公开实验摘要

数值来自原机 2026-09-11/12 的已保存报告。原始采样含现场地址、客户端信息与服务细节，未公开。下列 CSV 是摘要，不是匿名化后的逐包数据，不能从摘要重建所有统计检验。

| 文件 | 口径与局限 |
| --- | --- |
| [cpu-rps.csv](cpu-rps.csv) | 同一Steam下载两对短A/B，路由器接口吞吐；无新增空载基线 |
| [nss-ab.csv](nss-ab.csv) | 一组校内短对照，NSS实际加速数为0；不得解释成NSS性能收益 |
| [wifi-lan.csv](wifi-lan.csv) | 单手机固定位置LAN下载，第二轮只限制测试源；不是WAN吞吐 |
| [steam-proxy.csv](steam-proxy.csv) | 网卡接收短窗口；CDN/时长不完全匹配，确认旁路但无明显提速 |

额外记录：旧保守分流五分钟Steam客户端周期样本均值152.64 Mbps，路由器RX170.19 Mbps；15个国内探测组合无超时，最大P95/P99新增3.7/5.1 ms，手机视频正常。它发生在旧粘性PBR及不同max下，不能当成当前100/60方案的满载验收。

专用五路并发曾达到约460 Mbps量级；公开摘要不将其列为Steam或任意公网路径的保证。当前参数、接口速率、有效载荷、PHY协商速率、CAKE丢包与ICMP超时分别记录。
