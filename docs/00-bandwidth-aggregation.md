# 多账号带宽聚合：原理与适用范围

本项目关注的是：在一根物理上联上使用多个获授权校园网账号，让多连接应用和多台设备利用各路可用带宽，同时为游戏、视频和管理连接保留响应能力。雅典娜是当前验证这一方案的设备，不是原理的硬件前提。

## 聚合发生在哪里

每个 MacVLAN 提供独立虚拟接口，分别运行 MiniEAP 认证和 DHCP。各路获得可用网络后，连接调度器为新连接选择健康 WAN，将结果保存为 conntrack mark，由策略路由和 NAT 保持该连接的出口。

当前方案对健康线路等权分配新连接。假设五路各有约 100 Mbps 可用带宽，在共享上联、上游出口、CPU 和服务器均有余量，且应用产生足够分散的并发连接时，总吞吐才有机会接近五路之和。这个例子不意味着每个校园网账号都固定限速 100 Mbps，也不意味着每个下载都能占满五路。

| 概念 | 当前方案的行为 |
| --- | --- |
| 多连接总吞吐 | 多个连接可同时利用不同 WAN |
| 单个 TCP/QUIC 连接 | 不在连接内部拆分到多路 WAN |
| 网站出口 | 同一网站的不同连接可能使用不同 WAN；有固定出口需求时另设策略 |
| 等权 | 新连接分配机会相同，不保证每路实时字节数相同 |
| 线路故障 | 新连接避开故障线路；已有连接不保证无缝迁移 |
| 物理上联 | 多路共享同一端口、墙线及可能存在的上游瓶颈 |

因此，项目采用的“带宽聚合”是连接级负载均衡带来的效果，不是链路捆绑、MPTCP 或需要远端汇聚节点的隧道方案。当前生产参考实现使用自定义 nftables PBR，而非 MWAN3；不要同时套用两套未经协调的连接标记和调度规则。

## 保持低延迟的组成部分

1. **认证与线路健康**：每路 MiniEAP、DHCP 和路由独立，认证成功后还要验证实际连通性。
2. **连接与出口一致性**：保存和恢复 conntrack mark，避免一个连接随调度结果改变出口。
3. **每路整形**：上传 CAKE、下载 IFB+CAKE 配合 autorate；实际速率随质量反馈调整，base 不是硬上限。
4. **CPU 余量**：观察每核 softirq、吞吐及满载延迟，只有对照有收益才持久化 RPS/XPS；NSS 候选不能绕过 PBR 或 CAKE。
5. **可恢复部署**：改动前 checkpoint、独立超时回滚、配置验证和重启验收。

这些机制的具体实现和历史结果分别见[五路 PBR](03-five-wan.md)、[CAKE 与测量](04-cake-and-measurement.md)、[CPU 与 NSS](05-cpu-and-nss.md)和[运维](09-operations.md)。sing-box 网站策略是可选扩展；国内直连聚合不依赖代理节点。

## 迁移到其他设备需要确认什么

| 项目 | 当前公开内容 | 迁移检查 |
| --- | --- | --- |
| 认证 | MiniEAP 多实例参考脚本 | 所在网络认证方式、插件、账号权限与并发策略 |
| 线路数 | 五路参考实现 | 编译器、健康控制、mark、路由表及所有实例需一致修改，未实现任意路数配置 |
| 网口 | 原机 WAN / LAN4 命名 | 实际设备名、管理口、交换机结构及 MacVLAN 行为 |
| 整形 | CAKE/IFB 与 autorate 参数示例 | 内核模块、实际容量、共享瓶颈和 CPU 开销 |
| 多核处理 | 原机四核 RPS/XPS 实验 | 核心数、接收/发送队列、IRQ 与驱动路径；不可照抄掩码 |
| 加速 | 原机有线 ECM 未迁移 | 检查实际加速计数、PBR 标记和 CAKE 是否仍有效 |
| 固件与无线 | RE-CS-02 个案 | 使用目标设备自己的支持信息；不可套用原机分区或无线补丁 |

先在目标设备上完成只读识别和可恢复备份，再逐层验证一条线路、全部线路、连接调度、整形与重启恢复。[参考脚本](../reference/router/README.md)是带依赖说明的摘录，不是直接覆盖系统目录的安装包。面板编译器也会拒绝不匹配的五路基础配置。

历史脚本中的 `athena` 标识、服务路径和环境变量为兼容既有配置保留。项目更名不修改这些协议或要求对生产设备进行重命名。

## 如何报告结果

报告必须区分校内、国内校外、跨境和局域网路径。至少记录服务器与协议、连接数、每路及总吞吐、空载/满载 RTT 分位数、丢包、每核 CPU/softirq 和 CAKE 实际速率。单次峰值只能作为样本，不能作为生产保证。

现有约 460 Mbps 五路负载与约 350 Mbps Steam 样本说明此个案可以利用多个账号的带宽，不证明其他校区、设备、时段或应用有相同表现。最新参数与证据限制见[首页](../README.md)和[实验摘要](../evidence/README.md)。
